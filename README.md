**InfraNova AI** explores cross-spectral satellite image translation: synthesizing visible RGB imagery from paired Landsat 9 TIRS-2 thermal infrared Band 10 and Band 11 inputs.

**Technical highlights**

- **Model:** PyTorch Pix2PixHD-style conditional GAN with a Global ResNet generator and multi-scale discriminator.
- **Input/output:** Two thermal bands in; three-channel synthesized optical RGB out.
- **Inference API:** FastAPI, including health checks, colorization, thermal preview, and CLAHE post-processing endpoints.
- **Web app:** React + Vite interface with GeoTIFF/NPY support, tiled whole-raster inference, test-time augmentation controls, synchronized visual comparison, and inference telemetry.
- **Scale:** The active Exp9 generator has approximately **11.37 million parameters**.

The repository reports held-out evaluation on **1,259 test samples** for Exp9, including **13.7447 dB PSNR** and **0.4502 SSIM**. Its evaluation also reports improved YOLOv8 detection F1 versus the previous production baseline. Histogram-distance performance remains a documented trade-off.
